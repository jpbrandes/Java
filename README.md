# Java
Esse repositório contém códigos de treino em Java.

Cada pasta corresponde a um sistema simples com determinadas funções.

- MetodosEstaticosVetores: sistema de cálculo de vetores com números predefinidos.
- SistemaBancarioElaborado: sistema bancário mais complexo.
- SistemaBancarioSimples: sistema básico de conta corrente.
- SistemaEstoque: sistema básico de estoque.
- Cartao: sistema de entrega de cartão.
